## Welcome to the Hybrid Blog System

This is an example of an **internal article** hosted directly on this site. Unlike external Medium posts, these articles:

- Live entirely in the repository as MDX files
- Can be edited with full version control
- Support custom components and interactivity
- Have the same beautiful card design as Medium posts

### Features

#### Rich Markdown Support

You can use all standard Markdown features:

- **Bold text**
- *Italic text*
- `Inline code`
- [Links](https://example.com)
- Images
- Tables
- And more!

### Publishing Workflow

To publish a new article:

1. Create a new `.mdx` file in `/content/articles/`
2. Add frontmatter with title, description, category, etc.
3. Write your content using Markdown/MDX
4. Commit and push — your article appears automatically!

### Categories

Articles can be organized by category. The current categories include:
- SaaS
- Fintech  
- Analytics
- Pricing

The category filter at the top of the Articles page makes it easy to browse by topic.
